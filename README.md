# Webまなび帳

これまでに作った自作アプリ（筋トレ記録カレンダー、画像かんたん編集、抽選ツール、リバーシ、Gitまなび帳）で使った Web 技術やサービスを学ぶためのアプリです。
技術ごとの解説と、「自分のアプリでの使われ方」を合わせて読めます。

**▶ アプリを開く: https://trendgoing-stack.github.io/web-manabi/**

登録やログインは不要です。無料で使えます。

> [!NOTE]
> 現在開発中です（フェーズ1：検索・詳細画面・アプリ一覧）。お気に入り、クイズ、オフライン対応などは順に追加します。

## できること

- **探す** — 技術名でも、カタカナ・ひらがな・英字でも探せます。カテゴリ、レベル、アプリで絞り込めます。検索語が空のときは、カテゴリ一覧と「アプリから探す」を表示します
- **技術の解説** — 「何か」「なぜ必要か」「仕組み」「落とし穴・iOS Safari での注意」を、初心者向けのやさしい言葉で説明します。説明文中の用語をタップすると意味を確認できます
- **自分のアプリでの使われ方** — その技術を、どのアプリのどのファイルで、どう使ったかを紹介します
- **アプリ** — アプリを選ぶと、そのアプリで使った技術の一覧をカテゴリ別に見られます
- **用語集** — 五十音順に並んだ用語を検索できます

## ご利用にあたって

- 説明文はすべてオリジナルの要約です。正確な仕様は、各項目の参考リンク（公式ドキュメントや MDN）で確認してください
- ブラウザの対応状況やサービスの仕様は変わることがあります。最終確認から一定の日数がたった項目には「要再確認」のバッジが付きます
- 「未確認」のバッジが付いた項目は、作者が内容を確かめる前の下書きです

## 開発者向け

ビルド不要の静的サイトです（バニラ JavaScript の ES Modules ＋ HTML ＋ CSS。外部ライブラリや CDN は使いません）。学習データの書き方は [CONTENT.md](CONTENT.md) にあります。

### 手元で動かす

```bash
python -m http.server 8766
```

http://localhost:8766/ を開きます（ファイルを直接開くと動きません）。

### データの検証

```bash
node tools/validate-cli.mjs
```

ブラウザで http://localhost:8766/tools/validate.html を開いても同じチェックができます。

### 公開（GitHub Pages）

`main` ブランチの `/ (root)` を GitHub Pages で公開しています。`main` に push すると、数分で公開中のアプリに反映されます。
